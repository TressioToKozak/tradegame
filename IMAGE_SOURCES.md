# Źródła fotografii

W tej wersji nie wykorzystano żadnej fotografii produktu. Nie znaleziono ani nie przyjęto licencji pozwalającej na ich dystrybucję. Widoczne karty z inicjałami JW są typograficznymi placeholderami, nie przedstawiają butelek.

Aby dodać zdjęcie: umieść je w `public/images/whisky/`, zapisz autora, oryginalny URL, licencję, datę uzyskania i wymagane oznaczenie autorstwa tutaj. Następnie dodaj identyfikator do `whiskyImages` w `src/catalog.ts`. Nie przypisuj zdjęcia innej edycji.
